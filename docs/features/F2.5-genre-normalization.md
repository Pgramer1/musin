## 1. Purpose

RQ1–RQ3 classify every artist by a single **primary genre** (PRD §5), but MusicBrainz has 2,212 official genres and noisy, user-voted tags. This feature maps tags to official genres, official genres to **15 parent genres**, builds each artist's genre-share profile (`artist_genre`) and primary genre (`nodes_artist.primary_genre`, `genre_votes`, PRD §8.1), and reports coverage. It has a hard 1-day timebox (RULES §3): the mapping only needs to be good and documented, not perfect.

## 3. How it works

### 3.1 Parent genres and the mapping (D-024)

**15 parents:** rock · metal · punk · pop · electronic · hip hop · r&b & soul · jazz · blues · classical · folk & world · country · latin · reggae · experimental. The scheme loosely follows Discogs' top-level styles (a widely used music taxonomy), with **metal and punk split out of rock**, because they are large, distinct scenes in MusicBrainz (metal alone has 6.1 % of mapped votes), and with **experimental** kept as its own parent, because noise, drone, and avant-garde are a large MusicBrainz community (4.5 % of votes) that fits nowhere else.

**How 2,212 genres were mapped inside the timebox:**

1. A vote table for all official genres: artist-tag and release-group-tag votes, positive only, matched by name or alias. 379 genres have no votes at all. Votes are concentrated: the top 300 genres hold 94.7 % and the top 750 hold 99.4 %.
2. A **head-noun rule**: the genre name's last word decides ("pop rock" → rock, "folk metal" → metal, "jazz rap" → hip hop, "pop punk" → punk), with a keyword table per parent.
3. **308 manual decisions** where the rule was wrong or the genre ambiguous. Every genre above about 100 votes was reviewed by hand. Examples: synth-pop → pop, post-punk → rock, country rock → country, disco → r&b & soul, trip hop → electronic, singer-songwriter → folk & world, psytrance → electronic, big band → jazz. A conflict scan flagged names containing another parent's keyword (e.g. "punk rock" first came out as rock) for review.
4. **Non-style tags left unmapped on purpose:** instrumental, lo-fi, non-music, comedy, spoken word, christmas music, children's music, ASMR, interviews, and similar. They describe form or occasion, not musical lineage.

The CSV is the source of truth: the stage reads only `genre` and `parent_genre`, and `basis` documents provenance. `check_mapping` fails if the CSV and the dump's genre list differ, so a new snapshot or a typo cannot silently change which tags count.

### 3.2 Tags → artist profile (D-025)

1. A tag counts for an official genre if its name equals the genre's name or an alias, case-insensitive (D-015). That gives 2,558 genre tags, 1,748 of which vote for a parent. A tag that matches two genres with the same parent votes once.
2. **Artist source:** `artist_tag` votes > 0, summed per parent.
3. **Release-group source:** `release_group_tag` votes > 0 per release group, inherited by the release group's **main** credited artists only. Release-group credits are parsed with the F2.2 rule, so a guest on "A feat. B" doesn't take on A's album genre.
4. **One source per artist:** the artist's own tags if any map to a parent, otherwise the release-group tags. Artist tags are a direct judgement of the artist; release-group tags describe works and are ~10× more numerous, so summing them would drown out the artist-level signal. The fallback nearly triples coverage.
5. Special artists are dropped by joining `clean/artists` (FR-04).
6. **Shares:** `votes / artist total`, summing to 1. **Primary genre:** highest share, ties broken by alphabetical parent name (PRD §8.1); `tied` records that a tie happened.

*Rejected:*

- **Artist tags only.** 9.9 % of credited artists would get a genre, leaving RQ1–RQ3 with few labelled edges.
- **Summing both sources.** Release-group votes dominate.
- **Propagating release-group tags to every credited artist.** That mislabels featured guests.
- **A minimum-vote threshold for a primary genre.** It would be a new analysis parameter that the PRD doesn't define; the evidence is reported below for G1 instead.
- **Fuzzy tag matching** ("hiphop"). Out of timebox scope (D-015).

**Worked example (tests).** An artist with own tags rock 3 and pop 1 gets shares 0.75 / 0.25 and primary genre rock. An artist with only release-group tags rock 2 and hip hop 2 ties at 0.5, so the primary genre is **hip hop** (alphabetical) and `tied` is true. A guest featured on a rock album inherits nothing.

## 6. How to run

```bash
# needs clean/artists (F2.1) and clean/credits (F2.2); artist-level, full mode only
docker compose exec spark python -m musin.clean.genres --config config/pipeline.yaml
```

There is no `--sample`: genre profiles are artist-level and every sampled stage needs the full set (as in F2.1). Runtime on the reference machine: **45 s** (43.3 s wall time reported by the exec client).

## 8. Known issues and limitations

- **Thin evidence.** 29.8 % of labelled artists rest on a single genre vote and 11.4 % have tied top shares (alphabetical tie-break). RQ1's `min_labelled_neighbours` (5) limits the damage for diversity, but genre-composition results (RQ2) include these weak labels. G1 may want a minimum-vote rule; that would be a new `genres.*` key with a decision entry.
- **Coverage is 26.6 % of credited artists.** Most artists have no genre and drop out of genre metrics (PRD §5 genre attribution rule). Coverage is better weighted by activity (69.9 % of appearances), so labelled edges are mostly well-documented artists, and the results lean towards them.
- **Electronic and rock dominate** (45 % of labelled credited artists), reflecting MusicBrainz's contributor base; RQ1's genre matrix and RQ3's shares inherit this.
- **Parent boundaries are judgement calls:** synth-pop (pop vs electronic), post-punk (rock vs punk), disco (r&b & soul vs electronic), new age (electronic). They are documented row by row in the CSV (`basis = manual`) and can be changed by editing one line and re-running F2.5 onward.
- **Untouched long tail:** 955 genres stay unmapped, including 379 without votes. Unmapped genres with votes are listed in `reports/tables/genre_unmapped.csv`; apart from the deliberate non-style tags they total about 0.4 % of votes.
- **Classical (OD1)** is a parent like any other here; whether to exclude or separate it is decided at G1 and applied in F3.1.
