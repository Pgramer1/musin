## 1. Purpose

The final report is the main deliverable (PRD §4): architecture, data processing, results, benchmarks and limitations. PRD §16 asks for each RQ to have defined metrics, figures, a written answer and a validation note, and for the benchmark to be reported with environment details.

## 2. What was built

`report/report.md`, about 5,800 words:
- an abstract, an introduction with related work, and the data, architecture and ETL sections;
- methods, then results for RQ1–RQ4, degrees of separation and the sensitivity variants;
- benchmarks, discussion, limitations, reproducibility and conclusion;
- 12 references, and appendices for decisions and the build log;
- Figures 1–14 (16 images; Figure 6 is three ego networks) and Tables 1–19, linked from the generated files in `reports/`.

## 3. How it works

- **No typed numbers.** Every number in the text is copied from a generated file in `reports/tables/` (mostly the F6.1 report tables in `reports/tables/report/`), and the sentence names the table (RULES §9). After any re-run, `python -m musin.report` regenerates the tables and the numbers can be re-checked against them.
- **Every RQ follows the same pattern:** a figure, a table, a **validation note** and an **Answer to RQn** paragraph (PRD §16 criterion 2).
- **Figures and tables are linked, not copied.** The report embeds `../reports/figures/*.png` and links `../reports/tables/report/*.md`, so a regenerated figure appears in the report without editing it. In LaTeX, each table has a `.tex` twin to `\input`.
- **Limitations** list every parked G1 item (spoken word, betweenness reproducibility across imports, log weights, the D-027/D-028 sign-off), as decided, plus the data, method and benchmark caveats from P4 §7 and P5 §7.
- **Related work** cites only sources that were checked to exist: the three music network papers were confirmed by web search on 2026-10-20, and the method references are standard. One candidate paper that could not be confirmed was left out.
- *Rejected:* writing directly in LaTeX. The course format isn't fixed, and Markdown converts with pandoc to PDF, DOCX or LaTeX.
