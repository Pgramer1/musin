## 8. How to reproduce this phase

From WSL Ubuntu, repo root, with P1–P5 done and Neo4j holding `full` with its P4 write-backs:

```bash
docker compose exec spark python -m musin.report --config config/pipeline.yaml       # F6.1, ~2 s
docker compose exec spark python -m musin.demo_check --config config/pipeline.yaml   # F6.2 dry run, ~6 s
docker compose exec spark pytest
```

Then:
- **Demo:** open http://localhost:7474, drag `neo4j/10_demo.cypher` into Favorites, set its `:param` lines, and run the queries in order (F6.2 §6).
- **Report:** `report/report.md`.
- **Slides:** `report/musin-slides.pptx`.
